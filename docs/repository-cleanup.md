## 保留及必要调整

保留六页、8114 全部接口、联合反馈、路线/时间窗/装载/装卸检查、v1/v2 与独立六店案例、柏林/杭州 OSM 快照及来源授权、SKU 包装/导入/人工确认、城市配送全部原有检查和 Phase 6—9 资料。

两份仍被车厢引用的公共文件暂留原路径：

- `frontend/src/features/logistics/scene/create-scene.ts`：相机、灯光、交互、模型加载与车厢入口。
- `frontend/src/features/logistics/types.ts`：该场景的共享类型。

`city-delivery/workbench.css` 仍提供当前车厢样式；按钮、样式基础与工具函数也被六页实际引用。共享文件内部含部分历史类型/分支，本轮不为清理而重构。没有独立运行的制造业或联营页面留下。

效果页直接使用的三份历史城市配送计算证据，以及同目录相关城市配送记录，继续保留；名称含 `judge-evidence` 不代表属于旧制造业。

必要修改仅限城市独立入口、旧工作台链接退出、项目名称/描述/标题、构建路径、依赖与检查范围、README 和运行/许可说明。保留依赖版本没有升级。原有单元检查、浏览器用例与业务断言全部保留。
